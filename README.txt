Rider Cancellation Registration Data - Package
=============================================

Data Source
- East China rider cancellation registration survey
- South China rider cancellation registration survey

Data (2026-09-22 12:00)
- East China: 1152 records (raw)
- South China: 720 records (raw)
- Total raw: 1872 records
- After dedup: 1736 records

Files in this package:
1. rider_overview.html            - Comprehensive dashboard (Data + Stats + Field guide), with search/filter/sort/pagination & EXPORT
2. rider_dashboard.html           - Interactive dashboard, supports search/filter/sort + EXPORT current results
3. rider_share.html               - Share/print friendly page
4. rider_cancellation_summary.xlsx - Structured Excel (data + statistics sheets)
5. rider_qrcode.png               - QR code pointing to the shared folder
6. README.txt                     - This file

How to use:
- Open rider_overview.html or rider_dashboard.html in browser
- Use search box to filter by name/station/city/ID/phone
- Use region/zone/reason dropdowns to filter
- Click column header to sort
- Click "⬇ 导出当前结果" to download the current filtered rows as Excel-compatible CSV
- Auto-refresh every 3 hours
